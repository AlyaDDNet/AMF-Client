# AMF Client

**AMF Client** is a custom client for **DDNet (DDraceNetwork)** based on the latest DDNet versions.

It focuses on additional features, quality-of-life improvements, customization and a better overall experience while keeping compatibility with DDNet.

## ✨ Features

- Custom AMF Client features and interface improvements
- Built-in automatic update system via GitHub Releases
- Improved Discord Rich Presence integration
- Discord Low Priority mode
- AMF Client indicators in the server browser
- Additional customization and quality-of-life features
- Based on DDNet with upstream improvements and fixes

## 🎮 DDNet

AMF Client is based on **DDNet 19.9** and keeps the original DDNet gameplay and server compatibility while adding AMF-specific functionality.

## 📥 Download

The latest public version of AMF Client can be downloaded from the **Releases** section of this repository.

Download the latest `AMFClient-...-Portable.zip`, extract it to a folder and launch `DDNet.exe`.

## 🔄 Automatic Updates

AMF Client includes a built-in update system.

When a new AMF Client version is published on GitHub Releases, the client can detect and download the new version automatically.

User settings and personal data are preserved during updates.

## 💬 Discord

AMF Client includes enhanced Discord Rich Presence with activity information and AMF Client branding.

## ⚠️ Beta

AMF Client is currently in **Beta**.

Some features may change and bugs may still occur.
