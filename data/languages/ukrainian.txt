== Ви несете відповідальність за використання клієнта, його налаштування та власні дії на серверах.

Enable Run Statistics
== Увімкнути статистику забігів

Enables local Run Statistics collection and its UI. A run must be enabled before START.
== Вмикає локальний збір статистики забігів і вікно статистики. Функцію потрібно ввімкнути до старту.

Run Statistics
== Статистика забігів

Run Statistics cannot be enabled during an active run. Reset and start the run again.
== Неможливо ввімкнути статистику під час активного забігу. Зробіть reset і почніть забіг знову.
